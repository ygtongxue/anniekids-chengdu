- 在线地址：https://ygtongxue.github.io/anniekids-chengdu/
- 设计语言：高级童趣 Premium Playfulness（珊瑚红 × 奶油黄 × 鼠尾草绿）
- 内容：品牌介绍、学习路线图、课程体系、阅读特色、成都 18 家校区、品牌荣誉、预约表单

## 本地运行

直接双击打开 `index.html` 即可（图片引用云端永久链接，无需本地素材）。

## 更新发布

修改 `index.html` 后：

```bash
git add -A
git commit -m "更新内容"
git push origin main
```

GitHub Pages 会在 1-2 分钟内自动更新。
